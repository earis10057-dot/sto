# 내 블로그 문체 가이드

아래 내용을 내 스타일에 맞게 고쳐 쓰세요. 초안을 생성할 때 이 파일이 그대로 AI에게 전달됩니다.

## 말투
- 친근한 존댓말("~해요", "~거든요", "~더라고요")을 씁니다.
- 한 문장은 짧게 쓰고, 2~3문장마다 줄을 바꿉니다.
- 독자를 "여러분"이라고 부르고, 가끔 질문을 던집니다. (예: "혹시 나도 대상인지 궁금하셨죠?")
- 이모지는 섹션마다 1개 이하로만 씁니다.

## 구조
- 도입부: 독자의 고민을 짚는 2~3문장 + 이 글에서 알려줄 내용 한 줄 예고
- 본문: 소제목마다 핵심 한 줄(인용구) → 설명 → 필요하면 번호 목록
- 숫자·금액·날짜는 표나 목록으로 정리합니다.
- 마무리: 3줄 요약 + "도움이 되셨다면 공감과 이웃추가 부탁드려요" 같은 인사

## 반드시 지킬 것
- 확실하지 않은 금액·기간·조건은 지어내지 말고 [확인 필요]라고 표시합니다.
- 공식 출처(정부24, 복지로, 각 부처 등)를 확인하라는 안내를 넣습니다.
- 과장된 표현("무조건", "100%", "누구나")은 쓰지 않습니다.
